My learning-design cycle

Diagnose → Design → Teach → Check → Adapt

01

Diagnose

Use student work, scores, oral responses or a short screener to locate the actual gap.

02

Design

Set one clear objective and map the smallest useful prerequisite sequence.

03

Teach

Model explicitly, move into guided practice, then independent application.

04

Check

Look for error patterns and transfer, not worksheet completion alone.

05

Adapt

Change scaffolds, pacing, question type or challenge based on evidence.
